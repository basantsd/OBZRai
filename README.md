# OBZRai — AI Observer

An on-device Android companion that watches an authorized screen session, matches your topics, and saves full frames (plus audio/transcript when allowed) into a local, searchable library.

**Watch anything. Remember what matters.**

- Kotlin + Jetpack Compose
- MediaProjection screen capture with an edge-snap overlay
- On-device OCR and topic matching
- Room-based local library
- Privacy-first: no cloud
